# Запуск на своём компьютере

Сервис слушает порт 8000. Страница: http://127.0.0.1:8000/. Проверка: `GET /health`. Маскирование: `POST /process`.

Если порт занят и в терминале будет `address already in use`, остановите старый процесс или укажите другой порт в команде uvicorn и в адресе браузера.

## Без Docker

Нужен Python 3.12. Пары «оригинал → маска» живут в памяти процесса и пропадают после остановки.

```bash
cd "/.../hakaton-alfa"
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=. uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Проверка из другого терминала:

```bash
curl -s http://127.0.0.1:8000/health

curl -s -X POST http://127.0.0.1:8000/process \
  -H "Content-Type: application/json" \
  -d '{"payload":"Клиент Иванов Иван Иванович, паспорт 4509 123456","payload_id":"1"}'
```

Ожидаемый ответ: `{"result":"Клиент И. И. И., паспорт 45** ****56"}`.

Повтор того же запроса с тем же `payload_id` возвращает ту же маску. Другой текст с тем же `payload_id` возвращает исходную строку.

Остановка: Ctrl+C в терминале, где запущен uvicorn.

## Через Docker

Redis и шифрование пар, как на сервере. Перед первым запуском нужен ключ. Файл `.env` compose подхватывает сам, в git его не кладут.

```bash
cd "/.../hakaton-alfa"
python3 -c "import base64,os;print('PD_STORE_KEY='+base64.urlsafe_b64encode(os.urandom(32)).decode())" > .env
docker compose up --build
```

Остановка: Ctrl+C, затем `docker compose down`. Ключ в `.env` при следующем запуске оставляйте прежним, иначе уже записанные пары не прочитаются.
